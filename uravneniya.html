Вспомним правила

Решить уравнение — значит найти его корень (число вместо x). Ответ записываем так: x = число.

Как записывать решение:

  • Каждый шаг пишем на новой строке, под предыдущим.
  • В каждой строке только один знак «=».
✗ Так писать нельзя✓ Правильно
x − 23 = 45 = 45 + 23 = 68
x − 23 = 45
x = 45 + 23
x = 68
Ответ: x = 68

Правило 1. Простые уравнения: кто x?

x − a = bуменьшаемоеx = b + a8 − 5 = 3 → 8 = 3 + 5

Правило 2. Подобные слагаемые

Подобные слагаемые — это слагаемые с одинаковой буквой: 5x и 2x. Чтобы привести подобные, складываем числа перед x, а букву оставляем:

5x + 2x = 7x     9x − 4x = 5x

x и 5 — не подобные, их сложить нельзя.

Правило 3. Перенос

Слагаемое можно перенести в другую часть уравнения, поменяв знак: «+» становится «−», «−» становится «+». Слагаемое, которое остаётся на месте, знак не меняет.

План решения

  1. Группируем: слагаемые с x — влево, числа — вправо. При переносе меняем знак.
  2. Приводим подобные: получаем ax = b.
  3. Делим обе части на число перед x.
  4. Проверяем: подставляем корень в уравнение.

Пример: 5x − 8 = 2x + 7

5x − 8 = 2x + 7
5x − 2x = 7 + 8
3x = 15
x = 15 : 3
x = 5

Проверка: 5 · 5 − 8 = 17;  2 · 5 + 7 = 17;  17 = 17 ✓

Ответ: x = 5
