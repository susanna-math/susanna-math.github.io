1. Ի՞նչ է համակարգը

Երբ մի քանի հավասարում գրված են ձևավոր փակագծով { , դա կոչվում է հավասարումների համակարգ։

Համակարգի լուծումը այն թիվն է, որը միաժամանակ ճիշտ է դարձնում բոլոր հավասարումները։

Փակագիծը { նշանակում է «և». թիվը պետք է բավարարի և՛ առաջին, և՛ երկրորդ հավասարմանը։

2. Ինչպե՞ս լուծել՝ 3 քայլ

① Գտիր ամենահեշտ հավասարումը և լուծիր այն։
Սովորաբար դա այն է, որտեղ x-ը առանց աստիճանի է (x, 2x, 3x…)։
② Ստացված թիվը տեղադրիր մյուս հավասարումների մեջ։
x-ի փոխարեն գրիր այդ թիվը և հաշվիր։
③ Եզրակացություն
✅ Եթե բոլոր հավասարումներում ստացվեց ճիշտ հավասարություն՝ այդ թիվը պատասխանն է։
❌ Եթե գոնե մեկում սխալ է՝ համակարգը լուծում չունի (գրում ենք ∅)։

4. Օգտակար կանոններ

  • 🔹 Արտադրյալը հավասար է 0-ի, եթե արտադրիչներից գոնե մեկը հավասար է 0-ի։
    x(x + 2) = 0 → x = 0 կամ x + 2 = 0, այսինքն՝ x = −2։
  • ⚠️ Մի՛ բաժանիր x-ի վրա։ Այդպես կկորցնես x = 0 արմատը։
    x² = 5x → ճիշտ է այսպես՝ x² − 5x = 0 → x(x − 5) = 0։
  • 🔹 Բացասական թիվը կենտ աստիճանում բացասական է, զույգ աստիճանում՝ դրական։
    (−1)³ = −1,  (−2)² = 4
  • 🔹 Տեղափոխում. երբ թիվը տանում ենք հավասարման մյուս կողմը, նրա նշանը փոխվում է։
    x − 3 = −1 → x = −1 + 3 = 2
  • 🔹 Համեմատություն (երկու կոտորակների հավասարություն)՝ բազմապատկում ենք խաչաձև։
  • 🔹 Արմատներ.
  • 🔹 Քառակուսի հավասարում ax² + bx + c = 0։ Տարբերիչը՝ D = b² − 4ac։ Եթե D < 0, արմատներ չկան։
Հիմա անցիր 125 վարժությանը 👉

  3. Եթե բոլորը ճիշտ են՝ սեղմիր այդ թվի վրա։ Հետո սեղմիր «Ստուգել»։
