Главное правило. Квадратная скобка [ ] — число входит в промежуток (знаки ≤, ≥, точка закрашена). Круглая скобка ( ) — число не входит (знаки <, >, точка пустая). У бесконечности ∞ скобка всегда круглая.

Значение функции

Чтобы найти f(2), подставь 2 вместо x и посчитай. Отрицательное число бери в скобки.
f(x) = x² − 4x + 3
f(1) = 1² − 4·1 + 3 = 1 − 4 + 3 = 0
